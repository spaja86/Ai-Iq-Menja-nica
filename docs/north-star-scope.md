# North Star, KPI i Scope

## North Star
Ai Iq Menjačnica repo je **marketing + lead-generation platforma** za AI IQ World Bank ekosistem, uz **demo trading/wallet prikaze** za edukaciju i positioning.

## Nadređeni program
- `MONTEZACIJA NAD MONTEZACIJAMA` je repo-wide program koji upravlja načinom na koji se scope, funnel, trust i release povezuju.
- Program ne predstavlja zasebnu funkcionalnost, već nadređeni operativni okvir iznad pojedinačnih izmena.
- Cilj programa je `VRH PROGRAMSKOG EKVIVALENTA`: maksimalna usklađenost kvaliteta, sigurnosti, konverzije i governance-a.

## Primarni KPI (Top 3)
1. **Qualified inbound inquiries**: broj validnih upita sa minimalnim poslovnim podacima.
2. **Contact flow conversion**: procenat korisnika koji započnu i uspešno završe kontakt tok.
3. **High-intent engagement**: CTR na ključne CTA elemente (License, Partnerships, Institutional).

## Scope granice

### Zaključani program scope
- Centralni operativni hubovi su `services.html`, `contact.html` i `trust-center.html`.
- Sve nove inicijative moraju doprineti capability, qualification ili governance cilju.
- Scope ostaje marketing + lead-generation; full backend i neproverene regulatorne tvrdnje ostaju van trenutnog opsega.

### V1 (foundation)
- Struktura repozitorijuma i konvencije
- I18n baza i content model
- Security baseline
- Kontrolisani demo data signaling
- Unapređen contact flow (validacija + lokalna evidencija)

### V2 (operational uplift)
- Integracija realnih tržišnih izvora gde je moguće
- Analytics dashboard-ready event model
- CI quality gates i smoke checks
- SEO/PWA unapređenja

### V3 (platform expansion)
- Partner/admin operativni sloj
- White-label readiness model
- Jurisdiction readiness matrix
- Napredni compliance i enterprise onboarding tokovi

## Out of scope (trenutno)
- Direktna produkciona brokerska infrastruktura
- Full backend CRM/ERP integracije
- Regulatorne tvrdnje bez formalne pravne potvrde

## Approval kriterijumi scope-a
- Novi conversion CTA mora ostati merljiv.
- Formalni/regulatorni tokovi moraju ostati jasno odvojeni i direktni.
- Demo i simulated sloj mora ostati jasno označen.
- Javne tvrdnje i `docs/*` dokumenti ne smeju se razići.
